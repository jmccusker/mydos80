MyDOS/80 HWLINK Tester 0.1.0-E01 - getting started
===================================================
Copyright (c) 2026 Jim McCusker
Designed and developed by Jim McCusker using AI-assisted software
development tools.

The tester checks a real TRS-80 Model 4P from a Linux computer over a
serial cable: the serial link and the 4P's ROM serial loader, the CPU,
memory, video, keyboard, and (read only) the floppy controller and
drives. It writes one text report for you to send back. It never writes
to a disk.

This is evaluation release E01. Licence: personal, non-commercial
evaluation, education and testing; NOTICE.md (in this folder) is the full
text.

WHAT YOU NEED
- Fedora or Ubuntu (other Linux systems may work), with python3 3.10 or
  later: it is part of both systems already. Nothing else to install: no
  pip, no Git, no compiler.
- The 4P connected to the computer's serial port or USB serial adapter
  with a null-modem cable (the 4P's RS-232 port is DB-25, wired as DTE).

1. UNPACK (and check the download)
     sha256sum -c mydos80-hwtest-0.1.0-E01.tar.gz.sha256
     tar xzf mydos80-hwtest-0.1.0-E01.tar.gz
     cd mydos80-hwtest-0.1.0-E01
   (Optional: ./install.sh copies it into your home directory and adds a
   "mydos80-hwtest" command. It asks first and needs no password.)

2. CHECK THIS COMPUTER (changes nothing)
     ./mydos80-hwtest preflight
   It lists the serial ports and whether you may use them. If a fix is
   needed (usually: your user must be in the "dialout" group), it shows
   the exact command and why; the tester never runs such commands itself.

3. SELF-TEST (optional, no hardware, about 2 minutes)
     ./mydos80-hwtest selftest
   Runs the whole test against a built-in simulated 4P: it checks that the
   installation works. It must end with "SELF-TEST PASSED".

4. TEST THE 4P
     ./mydos80-hwtest
   and choose "RUN THE 4P TEST". Follow the instructions on screen: you
   will reset the 4P into its serial loader twice (hold RIGHT SHIFT while
   pressing RESET), press a few keys on the 4P once, and say what is in
   each floppy drive. Leave the drives empty at the start.

5. SEND THE REPORT
   At the end the tester shows "TESTING COMPLETE" and where REPORT.txt
   is (in ~/mydos80-hwtest-results/). Send that one file to Jim (see
   docs/TESTER_GUIDE.txt).

More: docs/USER_MANUAL.txt (every command, troubleshooting),
docs/TESTER_GUIDE.txt (what to expect, how to report).
